# LocalGig

LocalGig is a web platform that connects students and local clients for part-time gigs and freelance opportunities.

## Features

* Student Registration & Login
* Client Registration & Login
* Admin Dashboard
* Gig Posting System
* Application Management
* Reviews & Ratings
* Authentication & Authorization
* Responsive Frontend UI
* Backend API Integration

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MySQL

## Installation

### Backend Setup

```bash
cd localgig-backend
npm install
node server.js
```

### Frontend Setup

```bash
cd localgig-frontend/localgig-miniprojects6-main
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in backend folder and add:

```env
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=localgig
JWT_SECRET=your_secret_key
```
